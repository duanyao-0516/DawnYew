DawnYew offline OCR uses PaddleOCR Android SDK and PP-OCRv5 mobile models (Apache-2.0), ONNX Runtime (MIT), and OpenCV 4.14.0 (Apache-2.0) with its separately licensed components.

This software is based in part on the work of the Independent JPEG Group.

The vendored PaddleOCR files have been modified by DawnYew for resource bounds, lifetime management, CPU thread limits and model-configured BGR recognition input. See docs/implementation/ocr-native-build.md in the source distribution.

Model repository revisions and file hashes are in ocr/manifest.json. Original copyright notices are preserved in the corresponding source and license files.
