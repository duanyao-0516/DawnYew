# 首页与四栏导航实施计划

> 使用 subagent-driven-development 分工实现状态与首页组件，根线程整合页面入口并交叉 review。

**Goal:** 按用户明确布局，将四个主页面改为首页、统计、更多、我的，并完成真实账务驱动的首页卡片。

**Architecture:** 首页周期、今日与统计页使用各自的查询协调器，复用已验证的缓存、竞态隔离和受控文件返回恢复。首页只由账本和日期控制，搜索单独进入明细，不污染首页图表；明细保留为二级页。

**Tech Stack:** 既有 Kotlin Multiplatform、Compose Material 3、Room 聚合与原生 Canvas，无新增依赖。

## 约定

- 首页第一行仅左侧账本选择和右侧搜索图标，第二行复用日期范围控件。
- 第三行大卡展示周期净花销及曲线，注明净花销为支出扣除退款；未来未发生点不伪造消费，已存在的未来记录仍可显示。
- 随后一张“今日收支”卡展示今日收入与原始支出，退款单独列示。始终采用本机今天及所选账本，不跟随上方历史周期或搜索条件。
- 首页圆形悬浮按钮仅显示加号，无“记一笔”文字，保留无障碍描述和完整记账功能。
- 统计功能保留；按用户后续指示，更多先留空。我的承接截图记账、明细、账本/分类管理、回收站与备份/导入工具，以及应用锁、主题、本地数据清理和应用信息。继续完全离线，无账号系统。
- 首页搜索通过已有备注/类型/分类能力搜索所选账本和周期，结果为明细页；查看详情再返回仍回明细，回首页保留其周期。
- 沿用用户要求停止追加真机验证的指示：运行主机测试、编译及静态 review，完成后覆盖安装保留数据，不额外操控设备测试。
