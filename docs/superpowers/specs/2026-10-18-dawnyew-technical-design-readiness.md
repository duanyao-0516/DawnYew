## 技术设计应交付的内容

1. **总体架构与平台边界**：模块职责、依赖方向、共享代码范围、平台能力接口和依赖选型记录。
2. **领域与存储模型**：账本、分类、流水、退款、删除组、预算、草稿、来源信息和导入批次；金额与日期表示、约束、索引、事务及迁移策略。
3. **业务用例与界面状态**：创建/编辑/移动/退款/删除恢复的完整操作；页面上下文、取消、重复提交、落盘反馈和失败保留输入。
4. **统计查询协议**：期间与筛选、净支出、预算显示条件、等价数据表和下钻一致性；明确已发生日期补零与未来日期留空的界限。
5. **文件数据协议与任务流程**：JSON 版本及兼容策略、加密容器、表格往返身份、来源适配器、预检、预览、原子提交、取消、批次撤销与整体替换恢复。
6. **平台与安全状态机**：应用锁、外部分享/文件入口、进程生命周期、系统认证返回、临时文件清理及系统备份配置。
7. **验证计划与决策**：Android/KMP候选组合、离线OCR、XLSX与图表可行性门槛；实际执行后另写验证记录，不预填成功；本轮无iOS开发或验证。
8. **需求追踪与实现准入**：建立 `FR/NFR → 用例 → UI 状态 → 模块/接口 → AC/测试` 对照，说明每项未覆盖状态和完成条件，再拆分实现闭环。

优先顺序是先明确数据与事务不变量、平台边界及高风险验证，再完成协议与页面状态，最后形成实现计划。技术验证属于系统设计工作，不直接等同于产品工程已经具备开发或发布条件。
