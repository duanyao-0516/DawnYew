# SBTI 离线工具接入设计

基线：`a1e86d1`，当前工作树继续开发。用户指定来源并确认完整授权；沿用其此前“自行决策、留档、交叉审阅、无需反复提问”的工作方式。本轮实现功能并本地提交，不自动合并 master、推送、升版本或发布。

## 方案选择

采用 Kotlin 纯计分 + Compose 原生页面。直接包裹网页会引入另一套 UI/返回/状态机制；泛化成任意问卷引擎则会扩大重构范围。本轮保留 MBTI/SBTI 两个专属答题控制器，仅共享访问会话和平台通知入口，UI 复用现有平铺样式。

入口为“更多 / 我的 → 工具箱 → SBTI 测试”，与 MBTI 同级。全离线、无新增权限、无 WebView、无远程内容或运行时脚本；图片随应用打包。测试各自保存进程内进度，彼此重测/清除互不影响。

## 固定来源与算法合同

- 来源：<https://github.com/UnluckyNinja/SBTI-test>，提交 `6c24c9f2a4d3548010af44c9e1322c206f64f73d`。
- `index.html` SHA-256：`bfc7bbe66ae9a361220b2816651250b8769b0158c6aab8da882e6f8b2f22cea5`。
- 完整移植 30 道计分题、2 道补充题定义、15 个维度、25 个常规类型模板、27 种结果文案和图片、45 条维度解释。保留原作者与镜像署名；不将用户授权表述为上游附带开源许可证。
- 每次开始或确认重测，随机排列 30 道常规题，再将爱好题插入零基位置 1..30。会话期间顺序固定，后台/重建/离开页面不重新随机。
- 爱好题选择值 3（饮酒），立即在其后插入饮酒态度题，题数从 31 变为 32；改回其他答案必须移除补充题旧答案。选项按源 value 计分，不能使用按钮索引：q14、q27 的可见选项值为 3、2、1。
- 每维两题相加，分数 2..6；2..3 为 L，4 为 M，5..6 为 H。L/M/H 映射到 1/2/3，与 25 个模板做 15 维曼哈顿距离。
- 匹配度为 `max(0, Math.round((1-distance/30)*100))`。排序依次为距离升序、同档维度数降序、匹配度降序，完全同分维持上游模板顺序。
- 饮酒态度值 2 优先覆盖为 DRUNK；否则最高常规匹配度小于 60 时输出 HHHH；等于 60 不触发兜底。IMSB、WOC! 均是普通模板，不另加规则。
- 仅完整且合法的当前可见答案可评分。非法 ID、非法选项、缺答、未激活的补充题残留答案应拒绝。控制器负责清理隐藏答案，计分器不悄悄接受错误数据。
- 上游 IMSB 文案称“傻者”、海报写“自我攻击者”，保留来源差异并在来源记录说明。WOC! 使用 WOC.png，Dior-s / JOKE-R 使用 JPG。图片按原字节复制，不裁切重绘。

## UI 与结果

沿用 MBTI 的介绍、逐题、目录、结果四部分以及固定底部操作区。介绍说明“31–32 题、随机顺序、完全离线、仅供娱乐、进度仅保留在本进程”。选中后不自动跳题；题面和选项可滚动，长题完整显示；选项保持至少 48dp 触控区和完整读屏标签。答题时不显示计分维度。

目录、进度及“末题”状态基于当前可见题集合；点击目录使用稳定 questionId，不能依赖旧下标。补充题插入/删除推进交互 generation；当前题用 ID 定位，防止旧目录或旧下一题回调错跳。

结果显示原类型 code、中文名、原图（完整 fit）、intro、完整 desc、源匹配说明，以及 15 个维度的整数分、L/M/H 和原解释。保留娱乐提示与作者的话，匹配度明确是算法指标，不表述为准确率。源程序计算但未展示的 top3/secondaryType 不额外造页面。结果可回看改答、重测、清除；实际改答使旧结果失效，只查看不影响结果。

标题/系统返回先关闭目录或确认弹窗，再回上一题；首题/结果回介绍，介绍回工具箱。重测和清除有确认，取消不丢答案。

## 状态与整洁性

抽取最窄的 `PersonalityAccessSession`，统一数据作用域 `PersonalityDataScope(datasetId, epoch)`、访问可用性、交互 generation、数据变化清空、旧回调拒绝。两个专属控制器保留各自题序/题集/答案和结果，不做通用评分引擎。

`AppController.personalityTests` 统一向两个测试传播 `updateAccess`、`suspendAccess`、`synchronizeDataScope`。MainActivity 仍只有一套前台/解锁/无文件操作/无待确认操作门控，现有恢复和 ClearAll 的 finally 保持统一通知。数据相同情况下暂停隐藏投影但保留私有答案；数据 ID 或 epoch 改变时清除两个测试。答案不进入账本、Room、preferences、Bundle、备份或网络。

## 验收

源提取器只执行审读后的常量及纯算法于受限 VM，不执行整个网页。使用独立源 oracle 覆盖所有 25 个模板、DRUNK/HHHH、60 边界、反向选项和稳定同分；图片全量 SHA-256 对照。

控制器验证动态题出现/消失/再次出现、随机范围/会话稳定、回看改答、缺答定位、两测试互不影响、后台保留、代际清空、陈旧回调拒绝。共享会话改动必须跑原 MBTI 全部单测和真机用例。

只用已连接 OPPO 的 `.validation` 隔离包，不新增模拟器。验证普通完整作答、DRUNK、隐藏题清理、重建/后台/返回、长题与结果图片、暗色及大字体；恢复任何临时显示设置。编译/测试/源比对和独立审阅结果分层记录，不把单测称为心理测量效度证明。
