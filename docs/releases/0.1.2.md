# DawnYew 0.1.2

发布日期：2026-10-27。版本码：`3`。源码分支：`master`；Git 标签：`v0.1.2`。

## 本版变化

- “更多 / 我的 → 工具箱 → MBTI 测试”新增完整 MyMBTI 93 题测试，题库、计分和结果均离线运行。
- 支持五档作答、题号目录、已答进度、缺答定位、修改答案重新计分、重测和清除。结果展示四字母类型、中文名称和 E/I、S/N、T/F、J/P 八项原始分。
- 按用户指定的 MyMBTI 固定版本保留题面、映射、非对称权重和同分规则；全中立答案明确提示不能据此判断倾向。此版本不是官方 Global 量表。
- 答案和结果仅在本进程保留；后台隐藏并保留答案，恢复后可继续，数据替换或清空时清除测试。修复待确认账本操作独立变化时，MBTI 访问状态未同步暂停/恢复的问题。
- 应用继续无登录、会员、云同步或运行时联网权限；沿用原有账本数据格式和正式签名。

来源、算法对照、功能与验证边界见 [93 题实现记录](../implementation/2026-10-27-mbti93-verification.md) 和 [来源契约](../research/2026-10-27-mymbti93-source.md)。

## 构建与交付

```sh
./dev.sh check --offline --console=plain
python3 -m unittest discover -s scripts/tests -v
./dev.sh release --offline --console=plain
```

发布资产为 `DawnYew-v0.1.2-arm64-v8a.apk` 及同名 `.sha256`，使用既有正式密钥签名。签名材料、本机 Gradle 配置、私有截图及构建缓存不进入 Git 或 Release。

## 验证记录

合并后的主机测试、优化 Release、OCR JNI、Release lint、签名、16KB 对齐和最终资产摘要将在发布前按实际结果补齐。

MBTI 开发轮已在 OPPO PKM110（Android 16 / API 36）的独立 `.validation` Debug 包完成三项回归，以及 2.0 倍字体目录专项；这些是同一功能实现的设备证据，不作为最终签名 Release 的真机验收。完整财务、OCR、系统锁屏以及不同 OEM 设备矩阵未在本发布轮重新执行。
