# DawnYew 0.1.3

发布日期：2026-10-27。版本码：`4`。源码分支：`master`；Git 标签：`v0.1.3`。

## 本版变化

- “更多 / 我的 → 工具箱”在 MBTI 同级新增完整 **SBTI 测试**。题目、计分、结果解释和 27 张原版结果图全部离线提供。
- 每次开始随机排列 30 道常规题，并插入爱好题；选择饮酒时增加一道补充题，作答数量为 31–32 题。取消饮酒会清除补充题旧答案，再次选择后需要重答。
- 结果包含原版类型图文、十五维得分与解释，保留来源的普通类型、隐藏人格和兜底规则；支持题号目录、缺答定位、检查改答、确认重测与清除。
- 按用户指定的 [UnluckyNinja/SBTI-test](https://github.com/UnluckyNinja/SBTI-test) 固定版本移植。保留原作者署名和原图差异；测试仅供娱乐，匹配度不代表心理学准确率。
- MBTI 与 SBTI 共享前台和数据作用域访问门控，各自管理题序、答案及结果；进度只保留在本进程，不写入账本或备份。MBTI 的 93 题和计分规则保持不变。
- 应用继续无登录、会员、云同步或运行时联网权限；沿用原有账本数据格式、Logo 和正式签名。

来源及开发验证见 [SBTI 接入记录](../implementation/2026-10-27-sbti-verification.md) 和 [来源合同](../research/2026-10-27-sbti-source.md)。

## 构建与交付

```sh
./dev.sh check --offline --console=plain
python3 -m unittest discover -s scripts/tests -v
./dev.sh release --offline --console=plain
```

发布资产为 `DawnYew-v0.1.3-arm64-v8a.apk` 及同名 `.sha256`。使用现有正式密钥，不创建或更换签名；签名材料、APK、本机配置和设备截图不进入 Git。

## 设备验证边界

SBTI 开发轮已在 OPPO PKM110（Android 16 / API 36）的独立 `.validation` Debug 包完成 SBTI 三项、MBTI 三项回归及 SBTI 2.0 倍字体专项。组合执行曾有一次设备后台冻结相关的销毁超时；未改代码的独立重跑均通过，原失败记录保留。这些是相同功能实现的开发设备证据，不作为最终签名 Release 的真机安装验收。

本发布轮不重跑全部财务、OCR、系统安全锁屏、备份恢复或不同 OEM 的端到端矩阵；静态审阅、单测、编译和设备回归分别记录，不用互相替代。
