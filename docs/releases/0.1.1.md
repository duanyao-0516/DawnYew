# DawnYew 0.1.1

发布日期：2026-10-26。版本码：`2`。源码目标：`master`；Git 标签：`v0.1.1`。

## 本版变化

- 桌面图标、圆形图标和系统启动页统一使用用户提供的树形 Logo。原始 PNG 按字节保留，SHA-256 为 `a646d60981010123a3d7a801527a0dc1494d57830914605a62469c921d259eab`。Android 12 及以上由系统承载启动过渡；Android 11 使用居中的静态启动背景。不增加强制等待或额外的启动 Activity，截图中间页继续保持透明。
- 纳入此前开发的离线财务界面与功能：主页/统计面板长按排序与开关、完整月份和自定义区间、日历净收支、紧凑单页记账、账户/预算/周期交易/备份等。细节与已知边界见 [10 月 24 日交付说明](../implementation/2026-10-24-development-delivery.md)。
- 主动截图识别提取金额，显式正负号确认收入/支出，无符号默认支出；隔离 OCR 测试脚本可用文件名金额作为断言，不提交私有截图。
- 全局悬浮按钮通过系统无障碍截图能力在其他应用上触发离线 OCR；支持直接入账或保存前确认，结果通知可查看、修改、撤销。应用锁、请求失效与数据代际校验继续生效。此前设备证据见[浮窗记录](../implementation/2026-10-25-floating-capture-verification.md)。
- 猜拳保留为聚会工具；移除其他小游戏运行依赖，个人小游戏在 [XanaduYonder](https://github.com/duanyao-0516/XanaduYonder) 独立使用 Unity + C# 开发，当前仅 Android APP。历史方案和架构审阅归档一并提交。

应用继续完全离线，无登录、会员、云同步与运行时联网权限。

## 构建与交付

```sh
./dev.sh check --offline --console=plain
python3 -m unittest discover -s scripts/tests -v
./dev.sh release --offline --console=plain
```

最终发布 `DawnYew-v0.1.1-arm64-v8a.apk` 及同名 `.sha256` 文件，使用既有正式发布密钥签名。签名材料、本机工具链配置、私有测试截图和完整 OCR 输出均不纳入 Git 或 Release 资产。
