# 多 Agent 实现交叉审查闭环

2026-10-18。审查由领域/数据库、OCR/界面、加密/平台实现 agent 与独立验收审查 agent 分工，主线程独立读取关键代码并执行整包/设备验证。审查意见不直接当成测试结果。

| 发现 | 修复与证据 |
| --- | --- |
| 指针 rename 成功后 fsync/日志异常可能删除已生效候选，或继续写旧 delegate | 原子发布记录真实 rename 状态；异常关闭写入口，保留权威指针；故障注入回归 |
| 恢复预览可能覆盖预览后的新修改 | dataset/epoch/generation/contentVersion token 在读取前捕获，发布 mutex 内重验；过期预览拒绝 |
| 备份整库多次物化、取消粒度不够 | 按记录限额解析，磁盘归并排序，128 条/4MiB 分块、16 路归并，候选 Room 事务和稳定读快照导出；>20MiB、>10,000 条往返与取消回归 |
| 假分页和同步全量统计 | SQL WHERE/keyset/LIMIT 50；数据库聚合；版本冲突重读；真实 SQLite 10,000 条及设备基准 |
| 恢复遗漏删除组结构、JSON 属性限额 | 严格逐记录和跨行验证；根成员/退款关系、属性名/字段数/字节与未知字段提前拒绝 |
| OCR 旋转时仅保存部分字段，旧结果/旧回调污染新草稿 | 完整进程内 EditorDraft；operationId 防过期、无敏感 SavedState；新识别必须重新核对 |
| 旧画面整对象回写覆盖异步查重状态 | 字段级 EditorChange 合并当前状态；等待/失败/重复确认分别建模；确定性 race 回归 |
| 保存并继续重置类型和分类；恢复后默认分类按数组顺序随机变化 | 保留有效选择；统一按 sortOrder/id 选默认；分别有先失败再通过回归 |
| 图表缺少系列/指标，下钻扩大筛选范围 | 双系列、五指标、分类退款/净额和账本条形图、等价表；范围交集及零支出入口约束 |
| COMMIT 后、UI 确认前进程死亡丢失操作结果 | 提交前只落盘 UUID，启动查询回执/creationOperationId；用户明确确认后清标记；禁止新操作覆盖待确认结果 |
| 文件/认证返回复用失效会话、候选和密码遗留 | 进程内 lease/epoch、强认证、遮盖、安全窗口、取消清理及启动清理 |
| 候选在预览后损坏可能先激活后失败 | 发布前有界完整性/关系/SQL列与payload/计数/内容摘要重验，失败不改当前代际；真实 SQLite 及平台故障回归 |
| 归并第 k 个输入打开失败泄漏之前的句柄 | 打开与关闭统一纳入 try/finally，部分打开/关闭故障覆盖 |
| 数据库升级原地迁移未符合候选升级设计 | 候选迁移、raw probe/checkpoint、旧代保护与升级故障测试通过；真机 schema 2→3 保留旧 schema 2 保护副本 |
| 确定回滚的业务拒绝被 pending 恢复弹窗遮盖 | 仅对新操作、明确业务拒绝且 SQL 无提交证据清标记；旧标记/未知异常保留。4 组回归及最终 Release 真机删除引用分类复测通过 |
| Debug OCR 通过但 R8 Release JNI 崩溃 | 自建 ORT AAR 缺 consumer rules；补完整 JNI 包保留和最终 DEX 类/成员定义门禁。旧包红、新包绿；最终签名 Release 两次 OCR 与入账通过 |

独立 UI 复核确认三项 P2、pending 结果与偏好队列修复后未见新的 P1/P2。平台发布与解析问题经数据库 agent 交叉复核；最终构建、迁移及设备回归结果已记录在[验收报告](2026-10-18-device-acceptance.md)。真实 OCR 多厂商准确率、个人生物识别成功和系统级异常压力测试仍单独列在人工清单中。

最终 DEX 门禁经数据库/构建 agent 独立只读复核并重跑：确认检查实际 class_defs 与 encoded 成员定义、名称/完整 descriptor/所属类；129 类、3006 方法、1352 字段复现通过，Gradle 无任务循环。结合最终签名 Release 真机 OCR，未留 P1/P2 阻断项。
