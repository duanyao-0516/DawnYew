# DawnYew 人工验收清单

本清单列出本轮单台连接设备和自动化工具无法替代的验收。已执行的设备结果以同目录验证报告为准；未勾选不等于功能已通过。具体模板适配器按用户范围延期，不能在模板入口伪造成功。

## 系统身份认证

- [ ] 由设备持有人成功完成强指纹/强人脸认证并启用应用锁；冷启动、Home 返回和锁屏解锁后都要求认证。
- [ ] 使用系统 PIN/图案/密码后备；取消、失败、设备凭据移除及生物识别变更时不能绕过保护。
- [ ] 已锁定时从系统分享一张截图进入；认证前无缩略图、OCR 或账务数据，取消后不入账。
- [ ] 已启用锁时逐一导出、恢复、清空和清理保护副本，确认敏感操作重新认证；在文件选择器中 Home/锁屏、旋转和等待过期后返回不会复用失效会话。

本轮已验证系统指纹提示、密码后备按钮和取消后保持关闭，未输入设备持有人的凭据。

## 真实截图 OCR

- [ ] 至少 240 张获得授权且脱敏的真实样本，覆盖微信/支付宝不同主题和字号的成功消费、金额位置、优惠/余额、多金额及模糊截图。
- [ ] 危险负样本：退款、转账、收款、待支付、失败、多笔列表、长图；不得未经核对自动变成消费。
- [ ] 至少三家厂商，包含无 GMS 设备；首次安装断网后直接识别，不下载模型。
- [ ] 同图和同日同额给出疑似重复提示，分别核对继续/取消；退款与已有手工记录的误判不会自动删除或覆盖。
- [ ] 测量精确金额准确率、拒绝率、冷暖耗时、P95、峰值内存，以及从分享至保存的完整操作耗时。按技术方案门槛评审，不能用合成图片证明真实准确率。
- [ ] 连续取消/返回/锁屏压力、损坏模型资源、超大图片、旋转与进程死亡；无旧识别结果回填和原图残留。

本轮已在最终签名优化 Release 上完成真实 native 模型合成识别、待核对草稿、显式保存、同图/同日同额提示及双确认继续保存。该结果不能替代真实截图语料、多厂商和危险负样本验收。

## 平台与发布覆盖

- [ ] Android 11/12 及其他支持版本、多厂商 SAF；设备断电或强杀等系统级故障后的数据库与保护副本恢复。
- [ ] 真实 16KB 页大小设备加载全部 JNI。4KB 设备运行、ELF 16KB 对齐和 APK ZIP 对齐不能替代此项。
- [ ] 应用及系统受托组件的网络/DNS 观测为零、系统云备份与设备到设备迁移实际排除。当前静态清单/无遥测构建证据不替代全系统观察。
- [ ] 在技术方案的固定 Android 12/6GB/骁龙 778G 级基准设备上，以 Release 包、20 账本/10,000 流水各做 100 次冷启动、保存、月份切换并计算 P95。
- [ ] TalkBack、完整 200% 字号、横屏/小屏、深浅色所有页面；金额与图例可以被理解，主按钮始终可达。
- [ ] 5 名首次使用者完成建账、记账、移动、统计任务，记录成功率和耗时。

## 模板与表格后续输入

- [ ] 提供微信、支付宝和 DawnYew 模板的脱敏文件、版本、字段语义及预期结果后，实现并验收三个具体适配器。
- [ ] 使用 Microsoft Excel 和 LibreOffice 打开真实 codec 导出的 `.xlsx` 金样例；逐项核对金额、文本/换行/公式前缀、日期事实及再导入。当前没有完成这两款外部工具的人工互操作验收。
- [ ] 接通适配器后再完成业务导出、逐行预览、重复/冲突/退款依赖和撤销批次的全界面验收。现在仅交付受限 OOXML codec 与通用协议/事务基础。

## 密钥与分发

- [ ] 正式分发前配置独立发布签名并安全保管。此次设备交付使用仅存于本项目 `.local/signing/` 的开发密钥，Release 优化包不等于已完成商店发布。
- [ ] 升级到不同签名之前先导出并验证备份；不能直接用不同签名覆盖安装，也不应以卸载删除用户数据作为升级方案。
