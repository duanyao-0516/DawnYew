## 可达功能与数据边界

- 首页：选月收支趋势、最近 3 条活动、未入账、预算、月历、存钱入口与 11 项面板目录。活动与日期汇总来自 finance SQL 查询槽。
- 账户：8 类手工账户、初始余额与日期、归档 / 隐藏 / 计入资产、分组汇总、详情及账户流水。虚拟往来账户不能在普通账户选择器选中。
- 记账 / 流水：收入、支出、转账，账户、备注、日期、项目、商家、多标签、入账 / 预算 / 对账标记；详情编辑、退款、移账、回收站恢复与允许的清理动作。统一活动列表使用分页查询，支持来源筛选和继续加载。
- 往来：借入、借出、报销、联系人、追加本金、部分收付、结清、归档和流水修改；没有到期日不显示逾期。
- 周期：8 种频率，新增 / 编辑 / 暂停 / 继续 / 单期执行 / 跳过 / 归档及关联流水；展示 RecurringCoordinator 的真实生成结果、逐计划失败、待确认回执和 100 期上限，显式继续下一批。
- 预算：月总预算、分类子预算、同月转移和反向撤销记录；使用独立预算统计槽，不污染年度或月度图表查询。
- 存钱：4 场景、目标与进度、存取记录、愿望完成和取消；前三场景要求目标，随手攒钱可无目标。无账户仅影响进度；单端账户明确外部资金和净资产方向；双端按用户选择的 from → to 原样提交。
- 维度：项目 / 商家 / 标签管理、分类 / 联系人下钻。
- 我的：真实汇总、备份恢复、安全、设置、CSV 导入导出、导入批次撤销、回收站、提醒、桌面组件、工具箱、Debug 和本地 OCR。CSV 和 Widget 使用 PlatformActions；没有假导入、假添加成功或伪设置。

所有余额、往来未结清金额、存钱进度使用 core / repository 提供的查询结果。UI 只格式化和对已提供的派生值做展示分组，不维护第二份业务余额。原子操作提交一次 FinanceAction；错误保留表单，成功回调才关闭。

## 草稿及返回边界

- 新弹窗 operationId 与实体 ID 在打开时 remember；根按 transientGeneration 和 datasetId 重建。
- FinanceFormDialog 统一 dirty 放弃确认、busy 禁止重复提交、错误展示和 IME 避让。通过 LocalFinanceEditorPresence 引用计数阻止自动周期处理干扰金融草稿，金额入口同样登记。
- 账户 / 往来 / 周期 / 存钱的对象 ID 来自 FinanceNavigation；下钻活动后返回保留原对象，返回不从局部变量猜测。
- ROOT-UI-01：root 审查指出账户详情使用相同 page 导致仍被认作一级页。已将 primary 判定改为“五 Tab 且 financeNavigation.id 为空”，对象态显示顶部返回并隐藏底栏。
