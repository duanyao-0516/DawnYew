# 2026-10-24 纠正：可见入口与二级页审计

本审计记录纠正开发开始前的源码事实。仅阅读源码、既有实采文档和截图；未运行 Gradle、ADB，未修改应用源码。旧交付中的“受限空页”“会员暂不实现”不能解释当前可见的空入口，更不能视为验收通过。

## 关键结论

1. `DawnYewApp.kt` 对未知页面统一进入 `RestrictedPlaceholderPage()`；后者只有一个铺满屏幕的空 `Box`。当前存在 **49 个不同名称的可见空目标**：28 个面板配置目标、21 个其他目标。
2. `ProfileScreen.kt` 把登录、会员、共享、日志、活动、客服、评分、分享放在正常功能入口中；根页还显示 AI、消息，设置/备份显示自动同步/WebDAV。这与“离线、免登录”要求直接冲突，应移除。
3. “主页面板”和“统计面板”是 11/17 行 `SettingRow → onOpen("配置$title")`，没有开关、排序或持久化；根路由没有任何 `配置…` 的实现。用户指出的交互错误完全成立。
4. 账户、借还、周期、存钱的领域命令存在，但详情大多是堆叠操作按钮的 `AlertDialog`。这不是参考应用的二级详情页。统计三个详情也只是同一主卡 composable 增加展开列表，不能代表 17 种统计已实现。
5. 资金账户是现金、银行卡、转账、借还等离线业务对象，不能因为删除线上账号而删除。需要删除的是账号登录体系及空入口。

## 数据与实现责任

- 面板开关/顺序：稳定 panel id 与统一定义目录；保存启用集合及完整顺序。不能只保存在 `remember`。现有 `UserPreference` 可复用，但 `validatePreference` 严格白名单目前只有 theme、lastLedgerId、lastPeriod、lastBackupAt、amountDisplay、continueEntry、defaultAccountId。新增键必须同时通过命令、完整状态、批量备份恢复校验，旧备份缺键读时默认。
- 聚合：`StatisticsSnapshot.entries` 在生产查询不保证装载全量；禁止 Compose 扫描分页或首页近三条实现统计。新增聚合属于 shared core 的明确口径 + repository/storage 受限查询 + presentation 状态与失效处理。
- 资产趋势：Account 只有期初余额/时间及现有交易；真实余额来自该时间后的已入账交易/转账。需要日期维度历史余额与期末余额，包含转账双端、退款、未入账排除及余额隐藏行为；不能给当前余额画任意直线。逐笔余额需要定义同时间交易顺序。
- 信用卡账单概览：没有账单日、还款日、账单周期/明细归属模型；本轮删除面板是诚实边界。不得用 AccountType.CREDIT 即声称实现账单系统。
- 多人统计：没有作者或成员实体；本轮删除。Contacts 是往来人，不是记账作者。
- 周期与分期不同：RecurringPlan 是重复计划，不包含分期本金/利息/期数摊还关系；不展示分期假入口。
- 自定义统计：若未来显示新增/编辑，需真实 Definition 模型（稳定 id、名称、measure、grouping、filter、description、排序）及序列化/备份/校验闭环。本轮固定面板不能冒充这部分。
- 所有财务写入继续走已有 Command 单写门、operationId/版本控制和原单据专属命令。UI 不能另存账户余额、绕过恢复确认，或把专属存钱/借还流水编辑为普通转账。

## 对纠正技术方案的交叉审阅

已审阅 `docs/superpowers/specs/2026-10-24-ui-correction.md`。删除线上入口、10/16 真实面板、严格偏好、生产 SQL 聚合、二级详情和真实机验证的方向与证据一致，没有阻止开发的范围冲突。

落地前必须冻结这些接口/验收条件：

1. 账户详情需要只查询选中账户的活动页和历史余额；若该查询仍由根所有页面共用一份活动状态，页面切换必须清除/隔离范围和旧响应。非作者不能自行从 snapshot.entries 拼全量。
2. 二级详情可复用当前 `FinanceFrame.objectId`，但对象被删除/切换账本后必须返回列表或显示对应空态；返回键必须先退出详情而非直接回 Tab。
3. 默认面板本地数量分别为 10/16；目录标题/页脚由真实定义生成。实现 16 个详情时同步移除任何未实现“添加统计/编辑统计”承诺。
4. 删除通用空 Box fallback；未知 route 要成为可见错误/开发断言，并提供返回，不能继续静默成功。
5. 根接线、公共图表/卡片、业务详情作者分别拥有文件；改签名需先协商。每个保留按钮列入真机点击清单，编译成功不替代点击/视觉对照。
